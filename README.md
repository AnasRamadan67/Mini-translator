Word Teacher — Intelligent NLP Word Analyzer

Word Teacher is an interactive Python command-line application that demonstrates core Natural Language Processing (NLP) techniques in a simple and educational way. The program allows users to enter any English word and instantly receive an analysis that includes corrected spelling and the lemma (base verb form). This project is designed for beginners who want to understand how NLP works in real applications using Python.

The application uses the TextBlob library to perform spell checking and lemmatization. It runs in a continuous interactive mode, allowing users to analyze multiple words until they choose to exit. This makes it a lightweight and practical tool for students, developers, and anyone interested in artificial intelligence and language processing.

Features of the application include real-time word analysis, automatic spelling correction, verb lemmatization, an easy-to-use command-line interface, and a beginner-friendly code structure suitable for learning purposes.

This project demonstrates several important NLP concepts such as word normalization, linguistic processing, spell checking algorithms, and base-form extraction. It serves as an excellent starting point for more advanced NLP projects.

To run the project, Python 3 must be installed along with the TextBlob library and its required datasets. After installation, the program can be executed from the terminal, where users can type any word to receive an analysis. Typing "quit" will safely terminate the application.

The project is built using Python 3 and the TextBlob Natural Language Processing library. It is lightweight, fast, and does not require complex setup beyond installing dependencies.

Future improvements may include support for additional parts of speech such as nouns and adjectives, sentence analysis, graphical user interface (GUI) version, web-based implementation, part-of-speech tagging, and multilingual support.
